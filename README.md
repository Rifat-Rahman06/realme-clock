# Realme X Custom Alarm Manager

Target Device: Realme X (China ROM RMX1901) - Android 11.

## How to Build APK with GitHub Actions:
1. Upload these files to a GitHub repository.
2. GitHub will automatically trigger the workflow in '.github/workflows/build.yml'.
3. After ~2 minutes, go to the Actions tab and download 'realme-x-alarm-release-apk'!
